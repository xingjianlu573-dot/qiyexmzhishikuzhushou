# 企业案例：云帆科技企业知识助手

> 本案例为演示用虚构企业数据，用于作品集展示与功能演示；任何公司可直接替换 `seed/knowledge-base/` 下的文档为自身资料。

## 1. 客户背景

云帆科技（虚构）是一家提供企业级协同平台（YF-Suite）与边缘智能网关（YF-GW2000）的科技公司，员工约 1,200 人，覆盖研发、销售、交付、售后与内部 IT 支持。

## 2. 痛点（改造前）

| 痛点 | 现状 |
| --- | --- |
| 知识分散 | 产品说明书、技术文档、IT 运维 SOP、售后流程、FAQ 分散在网盘、Wiki、邮件与老员工脑中 |
| 检索低效 | 员工/客服平均每次人工翻找文档 15-30 分钟，一线客服首解率低 |
| 口径不一致 | 相同问题不同人回答口径不一，SOP 更新后旧内容仍被引用 |
| 依赖人工 | 高频问题重复咨询，占一线人力 40% 以上 |

## 3. 解决方案

以 Dify 平台为基础，交付"企业知识助手"应用：

1. **知识库统一管理**：5 大分类、12 篇文档集中入库，支持版本化更新（复用 Dify 知识库管理）。
2. **AI 问答带引用来源**：回答附带「引用：[文档名]」与前端引用卡片，可回溯、可审计。
3. **工作流自动处理**：命中知识库 → 结构化回答；未命中 → 兜底转人工（IT 服务台/工单），不硬答。
4. **防幻觉**：检索分数阈值 + 重排 + 强制引用提示词三层机制。

## 4. 效果（演示口径）

- 高频问题（VPN/邮箱/蓝屏/固件升级等）实现自助问答，一线人力释放约 30%。
- 回答口径统一，全部基于当前知识库版本。
- 引用来源可一键跳转到原始文档，审计留痕。
