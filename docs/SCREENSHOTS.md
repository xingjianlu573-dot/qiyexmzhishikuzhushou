## 真实截图拍摄指南（部署后替换）

部署完成（见 docs/DEPLOYMENT.md）后，按以下清单拍摄并替换 README 中的示意图：

1. **对话 + 引用**：打开 Web App，提问「VPN 连接超时怎么办？」，等待回答与引用卡片渲染后截图；再提问无关问题（如"今天天气"）截图兜底应答。
2. **工作流画布**：应用编辑页 → 工作流，拖动画布将 7 个节点全部框入，浏览器缩放至 80% 后截图（Windows 可用 Win+Shift+S 截取）。
3. **知识库管理**：知识库列表页，展开 5 个数据集，截图数据集统计卡片与文档列表。
4. **命中测试**（加分项）：知识库 → 命中测试，输入「邮箱发不出邮件怎么办？」，截图相似度分数与分段预览。

建议统一使用 1920×1080 或更高分辨率，PNG 格式。
