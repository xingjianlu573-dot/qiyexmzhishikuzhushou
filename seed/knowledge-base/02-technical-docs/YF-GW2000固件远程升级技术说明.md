# YF-GW2000 固件远程升级 技术说明

文档编号：TD-YF-011  
维护部门：硬件产品部  
最后更新：2026-08-15

## 1. 升级机制

YF-GW2000 支持两种固件升级方式：
1. 本地升级：通过 Web 管理界面"系统 → 固件升级"上传 `.bin` 固件包。
2. OTA 远程升级：设备定时（默认每天 03:00）向云帆 OTA 服务器轮询版本，发现新版本后自动下载并升级。

## 2. 升级前置条件

- 设备当前固件版本与目标版本之间的差异不超过两个大版本（否则需先升级中间版本）。
- 升级期间禁止断电、禁止断网（OTA 模式）；本地升级建议使用有线连接。
- 升级前建议导出设备配置备份（"系统 → 配置备份"）。

## 3. 升级流程

1. 检查当前版本：管理界面首页右上角显示固件版本号，格式如 `GW2000-v2.4.1`。
2. 下载目标版本固件包（本地升级），或确认 OTA 通道可用。
3. 执行升级，设备自动重启，重启后等待约 90 秒完成系统初始化。
4. 登录管理界面确认版本号，并检查"系统日志"中无异常报错。

## 4. 升级失败处理

| 现象 | 处理方式 |
| --- | --- |
| 升级后无法登录 Web 界面 | 等待 5 分钟后重试；仍失败则执行恢复模式：断电后按住 RESET 键 10 秒再上电 |
| 版本号未变化 | 检查固件包完整性（MD5 校验），重新上传 |
| 升级后业务数据丢失 | 立即导入升级前的配置备份 |
| 反复重启（boot loop） | 进入恢复模式刷入官方救砖固件，联系硬件产品部支持 |

## 5. 版本兼容性

- 协议插件（Modbus / BACnet / MQTT）随固件整体发布，不支持单独回退。
- 从 v2.x 升级到 v3.x 后，规则引擎配置自动迁移，无需重新配置。
