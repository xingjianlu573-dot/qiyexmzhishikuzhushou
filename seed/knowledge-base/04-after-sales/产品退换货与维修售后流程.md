# 售后流程：产品退换货与维修

文档编号：AF-YF-201
适用范围：售后服务部 / 客服中心
最后更新：2026-09-05

## 1. 流程目标

规范 YF 系列硬件产品（网关、传感器、边缘服务器）的退换货、维修与退款流程，明确各环节时限与责任人。

## 2. 售后政策总览

| 项目 | 政策 |
| --- | --- |
| 质保期 | 自签收日起 24 个月 |
| 7 天无理由退货 | 仅限未激活、外观无损坏的整机 |
| 15 天换货 | 非人为故障，凭检测单更换同型号 |
| 维修时效 | 签收返修件后 7 个工作日寄出 |
| 上门服务 | 企业客户质保期内提供免费上门检测（一线城市） |

## 3. 处理流程

### 3.1 客户报修
1. 客服记录：客户名称、合同号、产品型号、SN 序列号、故障现象、联系方式。
2. 远程初步诊断（30 分钟内）：指导客户检查电源、网线、指示灯状态。
3. 无法远程解决 → 创建售后工单并分配工程师。

### 3.2 检测与判定
1. 工程师 24 小时内完成检测，出具检测报告。
2. 判定结果：
   - 质保内非人为故障 → 免费维修 / 换货。
   - 人为损坏或过保 → 提供维修报价，客户确认后维修。
3. 检测结果同步客服，由客服与客户确认处理方案。

### 3.3 换货与维修执行
1. 换货：仓库 48 小时内发出新机，客户寄回旧机（运费企业承担）。
2. 维修：维修中心签收后 7 个工作日内完成并寄出，附维修工单。
3. 无法修复且质保内 → 换机或按合同约定退款。

### 3.4 退款
- 退款原路返回，7 个工作日内到账；企业客户开具红字发票。

## 4. 时限承诺与升级

- 一线响应：30 分钟内。
- 工单闭环：标准单 3 个工作日，复杂单 7 个工作日。
- 超时未闭环 → 自动升级售后经理，并同步客户预期。

## 5. 客户沟通规范

- 每个环节必须主动告知客户处理进度（短信 / 邮件 / 客服回访）。
- 维修报价需客户书面确认后方可执行，禁止未经确认产生费用。
