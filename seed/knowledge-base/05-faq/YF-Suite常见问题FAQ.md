# YF-Suite 常见问题 FAQ

文档编号：FAQ-YF-301
维护部门：客服中心
最后更新：2026-09-12

## Q1：YF-Suite 支持哪些操作系统和浏览器？

服务端支持 Linux x86_64 / arm64 与 Windows Server 2019+；客户端支持 Chrome 90+、Edge、Safari 14+ 及企业微信内嵌浏览器。移动端支持 iOS 15+ 与 Android 10+。

## Q2：单文件上传大小限制是多少？

即时通讯单文件最大 200MB，超出请使用平台网盘（单文件上限 5GB）。音视频会议单场最长 4 小时，超时需重新发起。

## Q3：如何与 AD/LDAP 集成实现单点登录？

在"系统管理 → 认证设置"中配置 AD/LDAP 服务器地址、Base DN 与绑定账号，启用后组织架构自动同步，员工通过企业账号即可单点登录。配置完成后请测试至少一个账号再全量启用。

## Q4：审批流程可以支持会签和条件分支吗？

可以。表单设计器与流程编排器支持会签、或签、条件分支、子流程，也支持退回、转办、加签、催办，全程留痕可审计。

## Q5：会议人数上限是多少？如何扩容？

标准版单会议最多 500 人，单集群支持 10,000 在线用户。扩容需联系销售评估并发配置，扩容在维护窗口内完成。

## Q6：数据安全与备份策略如何？

平台支持私有化部署，数据存储在企业本地。系统每日自动全量备份数据库与文件存储，保留 30 天；恢复演练每季度执行一次。

## Q7：集成第三方系统需要什么？

使用 YF-Suite OpenAPI（OAuth 2.0 认证），在"开放平台"创建应用获取 client_id 与 client_secret。常用接口包括组织架构同步、消息发送、审批发起与知识文档查询。调用限流默认 100 次/分钟。

## Q8：如何申请技术支持？

商业版客户拨打 4008 转 100 或通过官网提交工单，提供合同号与问题描述，按 SLA 优先级处理（P1 首次响应 15 分钟）。
