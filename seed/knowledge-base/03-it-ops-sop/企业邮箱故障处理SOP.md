# IT 运维 SOP：企业邮箱故障处理

文档编号：SOP-IT-104
适用范围：IT 支持一线 / 邮件二线
最后更新：2026-09-10

## 1. 目标

统一处理企业邮箱（YF-Mail）收发异常、登录问题与安全事件，保障邮件服务可用性，常见问题首解率 ≥ 85%。

## 2. 客户端配置标准

- 服务器类型：IMAP（推荐）或 POP3。
- 收件服务器：mail.yfcloud.cn，端口 993（IMAP SSL）/ 995（POP3 SSL）。
- 发件服务器：mail.yfcloud.cn，端口 465（SMTP SSL）。
- 认证方式：完整邮箱地址 + 应用专用密码（客户端不支持明文登录密码）。

## 3. 常见故障与处置

### 3.1 无法登录 / 密码错误
- 确认使用邮箱完整地址登录（例：zhangsan@yfcloud.cn）。
- 引导员工通过公司 SSO 自助重置密码，重置后需重新生成应用专用密码。
- 多次尝试被锁定时，等待 30 分钟自动解锁，或由二线后台解锁。

### 3.2 收不到邮件
- 检查是否误入垃圾邮件文件夹，白名单添加企业发件域。
- 查看邮件规则 / 转发设置是否异常（可能是账号被盗的征兆）。
- 服务器侧检查队列与退信（`mailq` 查看滞留队列），退信附退信原因为准。

### 3.3 发不出邮件
- 检查发件服务器端口 465 是否可达，本机代理是否拦截。
- 查看退信内容：
  - `550 5.1.1 user unknown`：收件人地址不存在。
  - `554 5.7.1 relaying denied`：认证失败，重新配置客户端。
  - `421 4.7.0 try again later`：发信频率超限，单账号默认 500 封/天。
- 群发前请使用平台的群发助手，避免触发反垃圾策略。

### 3.4 邮件延迟
- 大附件（> 20MB）建议使用企业网盘分享链接替代。
- 检查收件方网关与反垃圾策略；跨国邮件可能存在分钟级延迟，属正常。

## 4. 安全事件处置

- 疑似账号被盗（异地登录 / 群发垃圾邮件）：立即强制下线并重置密码，检查转发规则，必要时启用二次验证。
- 钓鱼邮件：员工举报至安全邮箱，安全组分析样本并全网通告。
- 邮件误发：立即联系收件方管理员请求撤回，并上报合规部门评估影响。

## 5. 记录要求

- 所有邮箱故障在 IT 服务管理平台建单处理，记录故障类型、处置动作与耗时。
- 涉及账号安全事件必须当天上报信息安全组。
