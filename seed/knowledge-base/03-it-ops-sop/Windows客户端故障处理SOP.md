# IT 运维 SOP：Windows 客户端故障处理

文档编号：SOP-IT-101  
适用范围：IT 支持一线 / 二线工程师  
最后更新：2026-09-10

## 1. 目标

统一 Windows 客户端常见故障的处理路径，保证故障在 30 分钟内完成初步定位，常见问题首解率 ≥ 80%。

## 2. 通用处理流程

1. 记录工单：员工姓名、工号、设备资产编号、操作系统版本、故障现象描述。
2. 远程连接（需员工授权），优先使用企业远程协助工具。
3. 按下方分类执行排查，每次操作后让员工验证。
4. 无法解决时升级二线，并保留完整排查日志。

## 3. Windows 蓝屏（BSOD）处理

1. 记录蓝屏代码（如 `IRQL_NOT_LESS_OR_EQUAL`、`MEMORY_MANAGEMENT`、`SYSTEM_SERVICE_EXCEPTION`）。
2. 查看 `C:\Windows\Minidump` 目录下的 dump 文件，使用 WinDbg 分析故障模块。
3. 常见根因与处置：
   - 内存故障（`MEMORY_MANAGEMENT`）：运行 Windows 内存诊断，更换内存条。
   - 驱动冲突（`SYSTEM_THREAD_EXCEPTION_NOT_HANDLED`）：进入安全模式，回滚最近安装的驱动。
   - 磁盘故障（`KERNEL_DATA_INPAGE_ERROR`）：检查磁盘 SMART 信息（`wmic diskdrive get status`），备份数据后更换硬盘。
4. 修复后建议执行 `sfc /scannow` 与 `DISM /Online /Cleanup-Image /RestoreHealth`。

## 4. 系统卡顿与开机慢

1. 查看任务管理器：CPU / 内存 / 磁盘占用 Top 进程。
2. 关闭自启动项：`任务管理器 → 启动`，禁用非必要程序。
3. 磁盘占用 > 95% 时清理临时文件（`cleanmgr`）与用户缓存。
4. 检查系统更新状态，补丁缺失可能导致后台高占用。

## 5. 打印机与外部设备故障

1. 确认设备电源、数据线连接正常。
2. 打印队列卡死：停止 `Print Spooler` 服务，删除 `C:\Windows\System32\spool\PRINTERS` 下文件，重启服务。
3. 驱动异常：卸载后从公司软件中心重新安装对应型号驱动。
4. 共享打印机无法连接：检查共享主机防火墙是否放行 445 端口，重新添加打印机。

## 6. 账号登录与域问题

1. 密码错误：指导员工通过公司 SSO 自助重置。
2. 提示"工作站与主域间的信任关系失败"：IT 在 AD 中重置该计算机账户，重新加域。
3. 登录后桌面异常：检查漫游配置文件大小，必要时重建用户配置文件。

## 7. 升级与转派标准

- 一线处理时长超过 30 分钟仍未定位 → 升级二线。
- 涉及硬件更换、域架构变更、批量故障 → 直接转派对应二线团队。
- 所有处置必须记录到 IT 服务管理平台，附解决步骤与耗时。
