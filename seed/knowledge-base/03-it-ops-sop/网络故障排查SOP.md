# IT 运维 SOP：网络故障排查

文档编号：SOP-IT-102  
适用范围：IT 支持一线 / 网络二线  
最后更新：2026-09-10

## 1. 目标

对"无法上网 / 网络慢 / 局部断网"三类典型网络故障，按标准路径在 15 分钟内完成定界（终端 / 接入层 / 核心 / 出口）。

## 2. 故障定界五步法

1. 确认影响范围：单人 / 单部门 / 整栋楼 / 全公司。
2. 单点故障先查终端：网线、Wi-Fi 信号、`ipconfig /all` 是否获取到正确 IP。
3. 终端正常则测网关：`ping 网关 IP`，通 → 排查上联；不通 → 检查接入交换机端口。
4. 网关通则测 DNS：`nslookup www.yfcloud.cn`，解析失败检查 DNS 服务器与转发。
5. 外部不通则测出口：`ping 114.114.114.114`，不通检查出口防火墙与运营商链路。

## 3. 常见问题与处置

### 3.1 获取不到 IP（DHCP 故障）
- 检查 DHCP 服务器负载与地址池余量（`dhcp pool exhaustion` 是常见原因）。
- 查看交换机端口是否启用 DHCP Snooping，误判可能导致地址请求被丢弃。
- 临时方案：静态配置可用 IP 并登记，待 DHCP 恢复后改回自动获取。

### 3.2 网速慢
- 带宽测试区分内网 / 出口：内网互传文件测速，慢则查交换机拥塞、环路（STP 收敛）。
- 出口慢：查看出口防火墙会话数与带宽利用率，识别 P2P / 视频大流量占用。
- 无线慢：检查 AP 信道干扰、接入用户数（单 AP 建议 ≤ 50 终端）。

### 3.3 局部断网
- 查看接入交换机电源、端口 err-disable（`show interface status`）。
- 环路排查：关闭端口后观察是否恢复，定位环路源端口。
- 配置漂移：对比交换机基线配置，回滚异常变更。

### 3.4 DNS 解析异常
- 内网域名解析失败：检查内部 DNS 权威区域与转发器。
- 部分网站打不开：测试公共 DNS（8.8.8.8 / 223.5.5.5）对比。
- 中毒 / 劫持风险：检查 hosts 文件与企业 DNS 是否被篡改。

## 4. 记录与升级

- 每个故障记录：时间、影响范围、定位结论、处置动作、验证结果。
- 涉及核心交换机 / 防火墙变更必须走变更审批，二线以上执行。
- 重大故障（影响 > 100 人或核心业务）启动应急预案并同步管理层。
