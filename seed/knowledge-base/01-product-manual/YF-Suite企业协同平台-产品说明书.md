# YF-Suite 企业协同平台 产品说明书

产品版本：v5.2.0  
文档编号：PM-YF-001  
维护部门：产品中心  
最后更新：2026-09-15

## 1. 产品概述

YF-Suite 是云帆科技自主研发的企业级协同办公平台，面向中大型企业提供"组织、沟通、流程、知识"四位一体的数字化工作空间。平台采用 B/S 架构，支持私有化部署与混合云两种模式，兼容 Windows Server / Linux / 国产化操作系统。

## 2. 核心功能模块

### 2.1 组织与通讯录
- 支持 LDAP / AD 域同步，组织架构自动同步，单点登录（SSO）。
- 通讯录支持部门分组、虚拟团队与外部联系人，权限按角色隔离。

### 2.2 即时通讯
- 支持文字、图片、文件（单文件最大 200MB）与音视频会议（单会议最多 500 人）。
- 消息已读回执、@提醒、会话归档，支持企业微信/钉钉消息联动。

### 2.3 流程审批
- 内置表单设计器与流程编排器，支持会签、或签、条件分支、子流程。
- 审批流支持退回、转办、加签、催办，全程留痕可审计。

### 2.4 知识中心
- 文档库支持目录树、全文检索、版本管理、多人协同编辑。
- 文档权限支持按部门 / 角色 / 个人三级授权。

### 2.5 日程与待办
- 个人日程、团队日历、会议室预定；支持 Outlook 日历双向同步。

## 3. 技术规格

| 项目 | 规格 |
| --- | --- |
| 服务端 | Linux x86_64 / arm64，Windows Server 2019+ |
| 数据库 | PostgreSQL 14+ / MySQL 8.0+ |
| 中间件 | Redis 6+ |
| 客户端 | Chrome 90+ / Edge / Safari 14+ / 企业微信内嵌浏览器 |
| 并发能力 | 单集群 10,000 在线用户（标准配置） |

## 4. 许可与支持

- 商业版按年度订阅，包含 7×24 技术支持与每季度一次升级服务。
- 标准版免费提供社区支持，升级周期为每半年一次。

## 5. 常见限制

- 单会话文件上传上限 200MB，超出请使用平台网盘。
- 音视频会议单场最长 4 小时，超时需重新发起。
- 移动端暂不支持离线审批与离线编辑。
