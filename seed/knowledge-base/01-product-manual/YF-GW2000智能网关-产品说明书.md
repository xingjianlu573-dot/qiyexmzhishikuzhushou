# YF-GW2000 智能网关 产品说明书

产品型号：YF-GW2000  
文档编号：PM-YF-002  
维护部门：硬件产品部  
最后更新：2026-08-30

## 1. 产品概述

YF-GW2000 是云帆科技推出的边缘智能网关，用于企业内部网络的统一接入与数据采集，支持 Modbus / BACnet / MQTT / OPC UA 等主流工业与楼宇协议，可作为物联网平台与现场设备之间的数据中转节点。

## 2. 硬件规格

| 项目 | 规格 |
| --- | --- |
| CPU | 四核 Cortex-A55，1.8GHz |
| 内存 | 2GB DDR4 |
| 存储 | 16GB eMMC + MicroSD 扩展 |
| 网络 | 双千兆以太网口（WAN / LAN）+ 4G 模块（可选） |
| 串口 | 2× RS485，1× RS232 |
| 供电 | DC 9-36V 宽压输入 |
| 工作温度 | -20℃ ~ 70℃ |
| 外壳 | 金属工业外壳，导轨式安装 |

## 3. 功能特性

- 协议解析：内置 Modbus RTU/TCP、BACnet IP、MQTT 3.1.1、OPC UA 客户端。
- 边缘计算：支持节点规则引擎，可在本地完成数据过滤、阈值告警与联动控制。
- 远程运维：支持 Web 管理界面、SSH、OTA 固件远程升级。
- 数据上云：通过 MQTT over TLS 连接云帆 IoT 平台，支持断点续传。

## 4. 快速使用步骤

1. 使用随机附带的电源适配器为设备供电（DC 12V）。
2. 将 WAN 口接入公司内网，等待约 30 秒自动获取 IP。
3. 在浏览器输入 `https://gw2000.local` 访问管理界面，默认用户名 `admin`，初始密码见设备铭牌二维码。
4. 登录后进入"协议配置"添加现场设备，选择协议类型并填写从站地址。
5. 在"数据上云"中填入 IoT 平台连接信息，点击"应用"后设备开始上报数据。

## 5. 安全注意事项

- 首次登录后必须修改默认密码，并建议关闭 SSH 的密码登录。
- 设备仅开放管理端口 443 与数据端口 8883，请勿暴露到公网。
- 固件升级过程中禁止断电，否则可能损坏系统分区。
